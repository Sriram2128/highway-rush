# 🏎️ HIGHWAY RUSH

### Ultimate 2D Arcade Racing Experience

Highway Rush is an exciting browser-based 2D car racing game developed using HTML, CSS, and JavaScript. Race through a dynamic highway, dodge incoming traffic, activate Nitro Boost, and challenge yourself to achieve the highest score!

## 🎮 Features

- 🚗 Smooth car movement and steering
- 🚦 Randomly generated traffic
- ⚡ Nitro boost system
- 🌧️ Animated rain effects
- ✨ Particle and visual effects
- 🔊 Sound effects
- 📊 Live score and speed tracking
- 🏆 High score saving
- ⏸️ Pause and restart options
- 📱 Mobile-friendly controls

## 🛠️ Technologies Used

- HTML5 – Game structure
- CSS3 – Styling and animations
- JavaScript – Game logic and functionality
- HTML Canvas – Game graphics and rendering
- GitHub Pages – Website hosting

## 🕹️ How to Play

| Control | Action |
|---|---|
| ← / A | Move left |
| → / D | Move right |
| SPACE | Nitro boost |
| P | Pause game |

On mobile devices, use the on-screen buttons.

## 🚀 How to Run

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Click Start Racing.
4. Enjoy the game!
